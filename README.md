# Dave A. Pagauitan Portfolio

A no-build personal portfolio made with HTML5, CSS3, and vanilla JavaScript. Open `index.html` directly in a browser.

## Editing content

- Update the editable data arrays at the top of `js/script.js` for skills, projects, and portfolio items.
- Add portfolio images to `assets/portfolio/`, then set each item's `image` path.
- The Portfolio section links to the additional public Google Drive archive containing `1st.png` through `5th.png`.
- Contact details, experience, education, languages, and resume-supported skills are now sourced from `Dave_Pagauitan_Resume_Simple.pdf`.
- The resume download links to `Dave_Pagauitan_Resume_Simple.pdf` in the project root.
- Add GitHub or LinkedIn links only when you have verified profile URLs to include.

Project and portfolio entries remain clearly marked placeholders because the resume does not list specific projects or provide portfolio images.
